# Interactive demo

A single static page — no build step, no server, no external libraries, no
network access. Open [`index.html`](index.html) in a browser, or serve this
directory (GitHub Pages, `python -m http.server`) and visit it.

Four tabs:

| tab | what it shows |
|---|---|
| **1 · The system** | the live Newton fractal of `z³ − 1` (pan/zoom), the 68 buried islands, a uniform training grid you can densify, and how many islands that grid actually samples |
| **2 · Resolution** | the same island at a controlled relative scale: ground truth vs the classifier's prediction for three capacities × six zoom factors, with the measured recovery / freeze rates |
| **3 · The evidence** | the measured curves: island recovery vs samples across (5 seeds), `w_c` vs capacity, peninsula recovery vs corridor thickness and along the root→tip axis, and what the paper's own protocol sees |
| **4 · The metric trap** | the same five models scored in-sample vs on a fixed population — the sign flip |

## Where the numbers come from

`data/*.js` and `fields/*.png` are generated by
[`experiments/make_demo_data.py`](../experiments/make_demo_data.py) from the
committed measurement files:

| asset | source |
|---|---|
| `data/islands.js` | the 3200² label raster (`separatrix.islands`) — island catalogue, masks, centroids |
| `data/cases.js` | the zoom experiment, retrained for this page (`separatrix.zoom`); also updates `results/island_zoom.json` |
| `data/stats.js` | `results/island.csv`, `results/thin.csv`, `results/geo.csv`, `results/demo_diagnostics.json`, `results/metric_bias.json`, `results/paper_protocol.json` |
| `fields/*.png` | the classifier's label field over each zoom window (palette-indexed: basin 1/2/3, plus "other") |

The fractal pixels and the "ground truth" panels are **not** precomputed: they
are Newton-iterated in the browser at display resolution
([`fractal.js`](fractal.js)), so zooming stays exact.

Regenerate everything after re-running an experiment:

```bash
python experiments/run_demo.py            # results/demo_diagnostics.json
python experiments/metric_bias.py         # results/metric_bias.json
python experiments/paper_protocol_check.py  # results/paper_protocol.json
python experiments/make_demo_data.py      # docs/data/*.js + docs/fields/*.png (~2 min)
```

`--no-train` reuses `results/island_zoom.json` instead of retraining the 18
networks for the field images.

## Conventions

* The window is `[−1.5, 1.5]²` of the complex plane, `x = Re z`, `y = Im z`.
* Islands are drawn in white; the selected one gets a blue ring. Clicking an
  island in tab 1 selects it and zooms to it.
* "Samples across" is `w/h`: feature width divided by sampling spacing. It is
  the x-axis of every scaling plot for a reason — it is the variable that
  governs both failure modes.
